# PRD — Bedtime Stories AI (Рабочее название: «Сказочник»)

**Версия:** 0.1 (Draft)  
**Дата:** 2026-05-31  
**Статус:** В разработке  

---

## 1. Обзор продукта

### 1.1 Концепция

«Сказочник» — iOS-приложение (сначала iPhone, iPad позже), которое генерирует персонализированные сказки на ночь с иллюстрациями с помощью ИИ. Родитель один раз настраивает профиль ребёнка, после чего каждый вечер получает уникальную историю — адаптированную по возрасту, интересам и выбранному миру.

### 1.2 Проблема

Родители хотят читать детям хорошие сказки, но:
- Качественных новых историй мало, знакомые быстро надоедают
- Кастомизация под конкретного ребёнка (его имя, хобби, любимых персонажей) вручную невозможна
- Нет единого инструмента, сочетающего текст + иллюстрации + сериальность

### 1.3 Решение

Приложение генерирует сказку по профилю ребёнка одним нажатием. Поддерживает:
- Короткие истории (5–10 мин чтения)
- Многочастные сериалы (7 дней / 14 дней / 30 дней) — по одной части в вечер
- Иллюстрации к каждой части, созданные ИИ в едином стиле

## 3. Функциональные требования

### 3.1 Профиль ребёнка

| Параметр | Тип | Описание |
|---|---|---|
| Имя | text | Используется в сказке («Маша отправилась в...») |
| Возраст | 2–12 лет | Влияет на сложность языка и длину |
| Пол (опционально) | выбор | Для согласования местоимений |
| Увлечения | multi-select | Динозавры, космос, лошади, роботы, море... |
| Любимые миры/жанры | multi-select | Средневековье, фантастика, джунгли, волшебный лес, подводный мир... |
| Любимый персонаж | text | Может появляться в истории |
| Язык сказки | select | Русский / Английский / другие |

**Ограничение:** не более 5 профилей в приложении (для семьи с несколькими детьми).

### 3.2 Форматы историй

#### Короткая сказка (Quick Story)
- Длина: 600–900 слов (~5–8 мин чтения взрослым вслух)
- 2–3 иллюстрации
- Генерируется за 15–30 сек
- Закончена в себе, без продолжения

#### Сериал (Story Arc)
- Длина дуги: 7 / 14 / 30 частей (на выбор)
- Каждая часть: 400–600 слов + 1–2 иллюстрации
- Единый сюжет, персонажи, стиль иллюстраций на весь сериал
- Разблокируется по одной части в день (или вручную родителем)
- Финал в последней части

#### Классическая сказка (Free)
- Пересказ известной сказки (Колобок, Красная Шапочка и т.д.) с персонализацией
- Доступно бесплатно (1 в день)

### 3.3 Читалка (Reading Mode)

- Тёмный и светлый режим (автоматически по времени суток)
- Крупный, удобочитаемый шрифт с регулировкой размера
- Иллюстрации показываются inline по ходу текста, с lazy loading и офлайн-кэшем для сохранённых историй
- Кнопка «Закладка» — запомнить место
- Кнопка «Воспроизвести» — TTS (text-to-speech) чтение (v2), с play/pause, скоростью чтения и таймером сна
- Поддержка премиального качества медиа: HD-изображения, облачные голоса, будущие видео-сцены
- «Режим ночника» — минимальный свет

### 3.4 Библиотека

- Все сгенерированные истории сохраняются локально + в iCloud
- Фильтрация: по ребёнку / по дате / по формату
- Избранное
- Кнопка «Поделиться» — экспорт истории в PDF

### 3.5 Ежедневная нотификация

- Push: «Пора читать сказку! Сегодня — часть 3 из 7 серии "Рыцарь и звёзды"»
- Настраивается: время и дни недели
- Тихий режим (выходные)

## 4. Монетизация

### 4.1 Модель подписки

| Тариф | Цена | Включает |
|---|---|---|
| **Бесплатный** | $0 | 1 классическая сказка/день, без сериалов, иллюстрации стандартные |
| **Family** | $6.99/мес или $49.99/год | Неограниченные короткие сказки, 1 активный сериал, HD иллюстрации |
| **Family+** | $9.99/мес или $69.99/год | Неограниченно всё, до 3 активных сериалов, 5 профилей, скоро: TTS |

### 4.2 Entitlement matrix

| Возможность | Free | Family | Family+ |
|---|---:|---:|---:|
| Профили детей | 1 | 3 | 5 |
| Классические сказки | 1/день | Без лимита | Без лимита |
| Quick Story | 3/неделю | Без лимита, fair use | Без лимита, fair use |
| Story Arc | Нет | 1 активный сериал | До 3 активных сериалов |
| Иллюстрации | Standard | HD | HD + расширенные стили |
| Аудио/TTS | Нет | On-device voice | Premium voices |
| Видео-сцены | Нет | Нет | Future add-on |
| Экспорт PDF | Watermark | Без watermark | Без watermark + расширенный экспорт |
| iCloud sync | Последние 10 историй | Полная библиотека | Полная библиотека |

Лимиты должны быть управляемыми с backend/remote config без релиза приложения. Если стоимость AI меняется, продукт может снижать fair use лимиты для новых периодов подписки, не ломая уже сгенерированные истории.

### 4.3 Пробный период

- 7 дней бесплатно для Family при первой установке (без карты)
- Онбординг объясняет ценность до пейволла
- В trial доступны Family-entitlements, но без Family+ premium voices/video add-ons
- По окончании trial пользователь переходит на Free, если подписка не оформлена

### 4.4 Paywall triggers

| Сценарий | Поведение |
|---|---|
| Пользователь достиг дневного/недельного лимита | Жёсткий paywall перед генерацией |
| Пользователь выбирает Story Arc на Free | Paywall с объяснением ценности сериалов |
| Пользователь включает HD-изображения, premium voices или будущие видео | Upsell на нужный тариф/add-on |
| Пользователь открывает paywall из настроек | Мягкий paywall с тарифами и restore purchases |
| Пользователь пытается создать профиль сверх лимита | Paywall перед сохранением профиля |

Paywall не должен блокировать чтение уже созданных историй. При downgrade новые генерации ограничиваются текущим тарифом, но существующая библиотека остаётся доступной.

### 4.5 Apple In-App Purchase (IAP / StoreKit 2)

- Подписки оформляются через Apple StoreKit 2
- Тип: `Auto-Renewable Subscription`
- Family Sharing: включено (один раз — для всей семьи)
- Управление подпиской — стандартный Apple UI
- Restore purchases доступен из paywall и настроек
- Backend валидирует App Store Server Notifications v2 и хранит server-side entitlements
- Grace period и billing retry сохраняют доступ к paid-entitlements до официального истечения статуса Apple

### 7.1 Ключевые события аналитики

| Событие | Когда отправляется |
|---|---|
| `app_open` | Открытие приложения |
| `onboarding_started` / `onboarding_completed` | Начало и завершение онбординга |
| `profile_created` | Создан профиль ребёнка |
| `story_generate_started` | Пользователь запустил генерацию |
| `story_generate_completed` / `story_generate_failed` | Генерация завершилась или упала |
| `story_read_started` / `story_read_completed` | Начало и завершение чтения |
| `paywall_viewed` | Пользователь увидел paywall |
| `trial_started` | Начат пробный период |
| `subscription_started` / `subscription_cancelled` | Изменение статуса подписки |
| `push_opened` | Пользователь открыл push-уведомление |

События не должны содержать имя ребёнка, полный текст сказки или другие чувствительные данные. Для анализа используются обезличенные `user_id`, `anonymous_id`, возрастной диапазон, язык, формат истории, тариф, источник установки и агрегированные признаки.

## 8. Analytics, Attribution и Privacy

### 8.1 Аналитика продукта

Цель аналитики — понимать воронку install → onboarding → first story → reading → paywall → trial → paid → retention. События отправляются из iOS-клиента и backend worker: клиент отвечает за UX-события, backend — за генерацию, ошибки провайдеров, подписки и usage limits.

MVP допускает Amplitude или Firebase Analytics. Названия событий и свойств должны храниться в shared schema, чтобы iOS и backend не расходились.

### 8.2 AppsFlyer / атрибуция

AppsFlyer используется для install attribution, paid acquisition cohorts, SKAdNetwork и deferred deep links. ATT prompt показывается после объяснения ценности продукта, а не на первом экране. При отказе от ATT продукт продолжает работать, но attribution ограничивается privacy-safe сигналами.

Минимальные атрибуционные свойства: `install_source`, `campaign_id`, `media_source`, `appsflyer_id`, `att_status`. Эти поля нельзя смешивать с данными ребёнка или текстами историй.

### 8.3 Consent и детская приватность

Поскольку продукт связан с детьми, аналитика должна быть conservative-by-default:
- Никаких имён детей, свободного текста профиля или сгенерированных историй в analytics events.
- Родитель управляет согласием на аналитику/персонализацию в настройках.
- COPPA / GDPR-K требования учитываются до запуска публичной beta.
- Данные для AI-провайдеров минимизируются и используются только для генерации контента.

## 9. Media Roadmap

| Версия | Медиа | Описание |
|---|---|---|
| v1 | Текст + изображения | Quick Story и Story Arc с inline-иллюстрациями |
| v2 | Аудио/TTS | On-device TTS для Family, premium voices для Family+ |
| v3 | Видео-сцены | Короткие bedtime video snippets как отдельный premium/add-on сценарий |

Все медиа должны быть частью одной модели истории: `story -> story_parts -> media_assets`. Новые типы медиа добавляются как расширение, а не как отдельная библиотека или отдельный продукт.

## 10. Риски

| Риск | Вероятность | Митигация |
|---|---|---|
| Качество генерации не нравится родителям | Средняя | A/B тест промптов, система оценки историй |
| Стоимость API (Claude + Image) выше прогноза | Средняя | Кэширование, лимиты на профиль, мониторинг unit economics |
| Apple отклоняет приложение (контент для детей) | Низкая | COPPA compliance, age gating, human review |
| Конкуренты выпускают аналог | Средняя | Фокус на UX и сериальность как дифференциатор |
| ATT opt-out снижает точность attribution | Высокая | SKAdNetwork, агрегированная аналитика, privacy-safe cohorts |
| Paywall ухудшает retention | Средняя | A/B тест triggers, мягкие upsell-сценарии, бесплатная ежедневная ценность |
| Видео и premium audio резко повышают стоимость | Средняя | Отдельные entitlements, лимиты, add-on pricing, асинхронная генерация |
