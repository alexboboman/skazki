# iOS-приложение «Сказочник»

SwiftUI, iPhone-first (iPad позже), iOS 17+. Референс экранов: `docs/design/prototype/` и `docs/product/UI_Flow.md`.

## Структура

```text
ios/
  Package.swift            Swift Package: весь код приложения
  Sources/SkazochnikCore/  Модели API, APIClient, сессия (Keychain), кэш, NarrationFetcher. Без UI
  Sources/SkazochnikUI/    Дизайн-система, экраны, RootView; Series/ (экран серии), Narration/ (чтение вслух)
  Tests/                   Тесты ядра (фикстуры с реального API) и рендер экранов
  App/                     Точка входа приложения (@main) и конфиг
  project.yml              XcodeGen: описание Xcode-проекта
```

Код лежит в пакете, а не в Xcode-проекте, чтобы ядро и экраны собирались и тестировались без Xcode (`swift build`, `swift test` на macOS). `.xcodeproj` генерируется из `project.yml` и не хранится в репозитории.

## Что сделано

- `SkazochnikCore`: модели (зеркало `packages/shared`), `APIClient` (гостевой вход, профили, сказки, entitlements, ошибки 402/422/401), токен в Keychain.
- `SkazochnikUI`: ночная тема, кнопки, чипы, аватар героя, онбординг (приветствие, 3 слайда, имя, возраст, внешность, интересы, мир), `RootView`.
- Онбординг создаёт гостевой аккаунт и профиль через API, затем идёт путь первой сказки как в дизайне: генерация (5 шагов, настоящий запрос `POST /v1/stories/generate`) → обложка → чтение → пейволл → «Готово».
- Генерация: `StoryGenerationModel` ведёт шаги по таймеру, пока идёт запрос; быстрый ответ всё равно проходит оставшиеся шаги. Ошибки: 402 открывает пейволл сразу (без ожидания шагов), 422 «сказка не получилась», нет сети и ответы сервера дают повтор.
- Чтение: сериф-текст, иллюстрации между абзацами, «Мораль сказки», финальная фраза, кнопка «Аа» (4 размера, запоминается), по дочитыванию на сервер уходит `readProgress: 1`. Экран принимает `ReadableStory`, поэтому подойдёт и для сказок из библиотеки.
- Главное приложение (`MainView`, после онбординга): нижняя панель «Сегодня», «Сказки», «Сочинить» (золотая кнопка), «Дети».
  - «Сегодня»: приветствие по времени суток, переключатель ребёнка, карточка «Продолжить» (начатая и не дочитанная сказка), карточка «Сочинить», «Недавние».
  - «Сказки»: поиск по названию (лупа в заголовке), фильтры «Все / Любимые» и по ребёнку, сетка карточек, сердечко, pull-to-refresh, удаление долгим нажатием на карточку (с подтверждением). Сказка с несколькими героями есть у каждого из них.
  - «Дети»: карточки с числом сказок, интересами и миром, выбор активного ребёнка. Меню на карточке: «Редактировать» (те же пять шагов с заполненными полями, последняя кнопка «Сохранить», язык и любимый персонаж сохраняются) и «Удалить» (с подтверждением; последнего ребёнка удалить нельзя, сказки остаются в библиотеке). Добавление ребёнка проходит теми же шагами без приветствия; при лимите тарифа показывается сообщение.
  - «Сочинить» (золотая кнопка и кнопка на «Сегодня»): для кого (до трёх детей, первый выбранный главный герой, «Аня и Миша будут героями вместе»), тема (6 готовых или своими словами до 300 символов, своё побеждает готовое, «Просто волшебная» ничего не шлёт), мир (шесть миров, по умолчанию мир главного героя, пока родитель сам не выберет), длина (~4 / ~7 / ~12 мин). Дальше генерация → обложка → чтение; из ошибки генерации «Назад» возвращает на форму. Запрос собирает `CreateDraft` (покрыт тестами). Картинки запрашиваются в HD, сервер сам понижает до standard на тарифах без HD.
  - Формат: «Одна сказка / Серия» и число частей 3 / 5 / 7 (`CreateDraft.arcLength`); серия идёт через `format: story_arc_part` и `arcLength`.
  - Блоки «Как слушаем» и «Голос рассказчика» из дизайна на «Сочинить» не сделаны: чтение вслух живёт в читалке (кнопка с наушниками), см. ниже.
  - Чтение из библиотеки: сердечко «любимое» в верхней панели, `readProgress` на сервер по дочитыванию.
- Серии: карточки с «Серия · 2 из 7», экран серии (`SeriesFlow`/`SeriesOverview`: прогресс, части, «Читать часть N» / «Сочинить часть N»), генерация следующей части тем же экраном (`StoryGenerationModel.Job.nextPart`), финальная карточка части в читалке, `PATCH readPart` по дочитыванию, пейволл «Серия уже идёт» при лимите. Обложка части 1 показывает первую иллюстрацию (`BookCover` с градиентной подложкой).
- Чтение вслух (`NarrationController`): голос устройства (`AVSpeechBackend`, лучший русский голос из установленных, пауза между абзацами, подсветка и прокрутка) и премиум-голос Family+ (`PremiumVoice`, `NarrationFetcher`: запрос к API с опросом, файл в `Caches/narration`, воспроизведение `AVPlayer`). Таймер сна, скорость, пауза, переключатель голоса, откат на голос устройства при ошибке или закрытом тарифе, `UIBackgroundModes: audio`, play/pause на экране блокировки. `AppModel` загружает entitlements и выдаёт читалке `PremiumVoice`.
- Офлайн: `LibraryRepository` кладёт профили, список и открытые сказки на диск (`FileLibraryCache`, Application Support, вне бэкапа) и при пропаже сети отдаёт их; ошибки сервера (401, 402, 5xx) не прячутся кэшем. Картинки кэширует `URLCache` (300 МБ на диске, настраивается в `App/SkazochnikApp.swift`). Сказка, которую не открывали онлайн, офлайн не откроется.

## Известные пробелы

- Пейволл только нарисован: покупка требует продуктов StoreKit 2 и интеграции App Store Server Notifications на бэкенде. Обе кнопки просто идут дальше. Цены и тексты взяты из прототипа, рублёвые цены не подтверждены.
- Если закрыть приложение посреди онбординга, при следующем запуске он начнётся заново и создаст ещё один профиль (гостевой токен остаётся в Keychain).
- Картинки грузятся через `AsyncImage`, он не умеет SVG. Мок-провайдер бэкенда отдаёт SVG, поэтому в dev вместо картинок показывается ночная сцена с героем (она же стоит, пока настоящая картинка грузится). Phygital+ и OpenAI дают WebP.
- Премиум-голос: первый запуск ~75 секунд на часть, во время подготовки можно переключиться на голос устройства; файл не удаляется из `Caches/narration`, пока система не почистит кэш. Нет выбора голоса и режимов «читаю сам / слушаем» на «Сочинить»; нет блокировки частей серии по дням и push-напоминаний.
- Гостевой аккаунт без пароля нельзя «войти заново»: токен обновляется при каждом запуске (`POST /v1/auth/refresh`, живёт 90 дней), а если сервер всё же перестал узнавать аккаунт, показывается экран «Не удалось войти в аккаунт» и единственный выход «Начать заново» (локальные данные стираются). Склейка с Apple ID (`signInWithApple`) есть в клиенте, но кнопки входа с Apple в интерфейсе пока нет.
- Группировка библиотеки по датам из дизайна не делается, подписи дат (`StoryDateLabel`) только на карточках «Недавние».

## Запуск в симуляторе

Нужен Xcode 16 или новее (проверено на Xcode 16.4, iOS 18.6, iPhone 16 Pro).

```bash
brew install xcodegen
cd ios && xcodegen
open Skazochnik.xcodeproj
```

API для симулятора. Без ключей хватит моков: текст отдаёт заготовка, картинки вместо иллюстраций рисуются сценой с героем.

```bash
TEXT_PROVIDER=mock IMAGE_PROVIDER=mock npm run dev:api
```

Premium-голос и серии на тарифе: у нового гостя 7-дневный триал Family, премиум-голос на нём закрыт. Чтобы его включить, дайте аккаунту Family+ (`PUT /v1/dev/subscription`, см. раздел Dev recipes в корневом README).

С настоящими ключами: впишите `ANTHROPIC_API_KEY` и `PHYGITAL_API_KEY` (или `OPENAI_API_KEY`) в корневой `.env` и запустите `npm run dev:api`: сервер сам читает `.env`.

Симулятор ходит на `http://localhost:3000`; адрес меняется ключом `API_BASE_URL` в `project.yml`. Bundle id `com.example.skazochnik` и версия — заглушки, их нужно заменить до TestFlight.

Из командной строки (если Xcode не выбран системно через `xcode-select`, помогает `DEVELOPER_DIR`):

```bash
export DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer
xcodebuild -project Skazochnik.xcodeproj -scheme Skazochnik \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro' build
```

**Если Xcode пишет «Missing package product 'SkazochnikCore'»** (бывает, когда проект пересоздали, пока Xcode его держал): закройте Xcode (⌘Q), затем

```bash
cd ios && xcodegen generate && rm -rf ~/Library/Developer/Xcode/DerivedData/Skazochnik-* && open Skazochnik.xcodeproj
```

Если не помогло: File → Packages → Reset Package Caches, затем Resolve Package Versions. Из командной строки `xcodebuild -resolvePackageDependencies` проходит, то есть сам проект в порядке. Не пересоздавайте проект через `xcodegen`, пока он открыт в Xcode.

Иконка лежит в `App/Assets.xcassets/AppIcon.appiconset`. Перерисовать: `APP_ICON_DIR=$PWD/App/Assets.xcassets/AppIcon.appiconset swift test --filter writesAppIcon`, затем убрать альфа-канал (App Store его не принимает): `sips -s format jpeg icon-1024.png --out /tmp/i.jpg && sips -s format png /tmp/i.jpg --out icon-1024.png`.

## Проверки без Xcode

```bash
cd ios
swift build
swift test
```

- Тесты ядра читают `Tests/SkazochnikCoreTests/Fixtures/*.json`. Это настоящие ответы `apps/api`, поэтому тесты падают, когда контракт API и Swift-модели расходятся. Фикстуры снимаются скриптом на tsx с in-memory БД и фейковым Claude (в репозиторий скрипт не входит; при смене контракта их нужно обновить).
- `ScreenRenderTests` рисует экраны в iPhone-размере через `ImageRenderer`. Чтобы посмотреть картинки: `RENDER_DIR=/tmp/renders swift test --filter ScreenRenderTests`. Ограничения рендера: нативное текстовое поле выводится жёлтой заглушкой, `ScrollView` разворачивается плоско (`snapshotMode`).

## Что проверено вручную в симуляторе

Пройдено на iPhone 16 Pro с моками API (`TEXT_PROVIDER=mock IMAGE_PROVIDER=mock`):

- Онбординг целиком (приветствие, слайды, имя с экранной клавиатурой, возраст, внешность со скроллом, интересы, миры), создание гостя и профиля через API, генерация с шагами, обложка, чтение (мораль, финальная фраза, сердечко), пейволл, «Готово».
- Главная, «Сказки» (избранное доходит до сервера, поиск, удаление долгим нажатием с подтверждением), «Дети» (меню карточки, редактирование с заполненными полями), «Сочинить» с темой.
- Лимит Free (`TRIAL_DAYS=0`): четвёртая сказка за неделю даёт 402, показывается экран «Бесплатные сказки закончились» и переход на тарифы с причиной.
- Офлайн: API остановлен, приложение стартует с плашкой «Нет связи — показаны сохранённые сказки», список и открытая ранее сказка читаются из кэша.
- Сервер не узнаёт аккаунт (чистая база): экран «Не удалось войти в аккаунт» и «Начать заново».
- Настоящие провайдеры (Claude Haiku для текста, Phygital+ `gemini-image` для картинок): онбординг, генерация (~25–30 с на сказку из трёх иллюстраций), обложка с первой иллюстрацией, чтение с текстом от Claude.
- Серии (настоящие Claude и Phygital+): выбор «Серия» и числа частей на «Сочинить», часть 1 с подписью «Серия · 3 части», карточка «Часть 1 из 3 прочитана», экран серии (прогресс, список частей, «Сочинить часть 2»), часть 2 продолжает героев части 1, бейдж «Серия · 1 из 3» в библиотеке.
- Чтение вслух голосом устройства: кнопка с наушниками в читалке, плеер (пауза, абзац вперёд/назад, скорость, таймер сна), подсветка читаемого абзаца и прокрутка за голосом. Сам звук в симуляторе не слышал, проверял по смене абзацев.
- Премиум-голос (Family+, Gemini TTS): первый запуск «Готовим голос… около минуты» (озвучка ~75 с), затем плеер с перемоткой на 15 секунд, повторный запуск мгновенный (файл лежит в Caches/narration), переключатель «Премиум-голос / Голос устройства». Звук в симуляторе не слышал, проверял по состояниям плеера и файлам.
- Переустановка приложения при старом токене в Keychain: онбординг сам берёт нового гостя и доходит до сказки.

Найдено и исправлено в процессе: аватар был смещён от центра (свечение раздувало ZStack), свечение выбранного возраста обрезалось, под верхней панелью чтения просвечивала иллюстрация, на пейволле список тарифов уходил под кнопку без затемнения, экран «сессия устарела» был полупрозрачным, в тексте лимита стояло «на сегодня» при недельной квоте (теперь с датой обновления из ответа сервера), поле поиска делало первую букву заглавной, у приложения не было иконки, после переустановки со старым токеном онбординг упирался в ошибку.

**Не проверялось в симуляторе:** заблокированный премиум-голос на Free/Family (подсказка про Family+, покрыта тестами), откат на голос устройства при ошибке озвучки (тесты), воспроизведение с заблокированным экраном и кнопки на экране блокировки, лимит активных серий и пейволл серии (покрыты тестами), завершение серии с моралью, добавление и удаление ребёнка (логика и сообщение о лимите покрыты тестами, но не руками), ответ 422 «сказка не получилась» на живом API, размер текста «Аа», жесты назад, тёмная и светлая темы устройства, Dynamic Type, VoiceOver, оффлайн-чтение настоящих картинок (WebP с сервера), шрифты Lora и Onest (пока не подключены), физический iPhone. Кириллицу в поле имени инструмент управления симулятором вводит искажённо (кодировка буфера), поэтому имя вводилось латиницей; сам экран кириллицу принимает.
